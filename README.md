## 📌 Project Overview

The Smart Community Problem Reporting System is a web application designed to improve communication between community residents and administrators.

Residents can report problems such as:

- Road damage
- Street lighting problems
- Waste management issues
- Water problems
- Drainage issues
- Security concerns
- Environmental problems
- Other community-related issues

Administrators can review submitted reports, monitor their status, view report locations, manage residents, and update the progress of reported problems.

The project was developed as a practical full-stack web development project to demonstrate skills in frontend development, authentication, database management, security, role-based access control, and deployment.

---

## 🎯 Project Objectives

The main objectives of the system are to:

1. Provide residents with an easy way to report community problems.
2. Allow residents to track the progress of their reports.
3. Provide administrators with a centralized dashboard for managing reports.
4. Implement role-based access control for residents and administrators.
5. Store report information securely in a cloud database.
6. Support location-based reporting using geographical coordinates.
7. Allow residents to attach photos to reports.
8. Provide a foundation for improving communication between communities and administrators.
